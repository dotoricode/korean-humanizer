## 사례. Community demo 또는 SaaS 제안 답변

### Raw

> 안녕하세요. 먼저 정말 감사합니다.
>
> 이 프로젝트를 보고 바로 실행해볼 수 있는 데모까지 만들어주신 게 처음이라, 개인적으로는 꽤 기쁩니다. 아직 작은 prompt/skill 프로젝트인데 누군가 직접 써보고, 더 쉽게 체험할 수 있는 입구를 만들어줬다는 점이 정말 반갑습니다.
>
> 방향 자체는 좋아 보입니다. 특히 README의 “Try It in 30 Seconds” 섹션은 지금도 사용자가 `PROMPT.short.md`를 직접 복사해서 써보는 방식이라, 설치 없이 바로 결과를 확인할 수 있는 데모가 있으면 확실히 도움이 될 것 같습니다.

### 적용 가이드

- "반갑습니다"는 사람을 만나거나 소식을 접한 인사성 맥락에 우선 사용한다.
- 외부 사람이 만든 결과물, 도움, 제안에는 "기쁩니다", "고맙습니다", "감사합니다"를 우선 쓴다.
- 제3자 hosted demo / SaaS 제안은 의도를 단정하지 않는다. 공식 README 연결 전에는 "community demo 제안인지, SaaS 링크 제안인지" 먼저 확인한다.
- 확인 뒤에는 입력 저장 여부, 사용 LLM/provider, 로그 보관 기간, 삭제 방법, unofficial/community demo 표기, 민감정보 입력 경고를 요청한다.
