# 채팅 / DM 도메인 — Raw vs Humanized

> 카톡 / 인스타 DM / 슬랙 thread 의 humanizer 적용. **친근 톤 strict 보존** — 강조어 1-2 개만 줄이고, 이모지는 0-1 개로. ~해요체 / 반말 디폴트.

---

## 메타데이터

| 항목 | 값 |
|---|---|
| 도메인 | 카톡 / DM (informal, 친근 격식) |
| 강한 카테고리 | #1 강조어, #10 이모지, #11 hedging |
| 톤 디폴트 | ~해요체 (반말 thread 면 반말 strict 보존) |
| 톤 보존 | 친근 표현·말줄임·"여러분 / 진짜 / 너무" 같은 친근 어휘는 1-2 회 살림 |
| 금지 변경 | 발신자·수신자 호명, 이모지를 0 개로 다 깎지 않음 (0-1 개 룰) |

### Humanized

> 안녕하세요! 정말 오랜만에 연락드려요. 😊 지난번 프로젝트 이후로 정신없는 시간을 보내고 있었는데, OOO님 잘 지내고 계신지 궁금했어요. 다음 주에 시간 괜찮으시면 가볍게 점심이라도 함께하면 어떨까 싶어서 연락드렸어요. 너무 부담 갖지 마시고, 가능하신 일정 편하게 알려주세요. 그동안 어떻게 지내셨는지 궁금해요. 답장 기다릴게요!

`6문장 / 약 200자 (-29%)`

### 변경 (5 곳)

| # | 카테고리 | Before → After |
|---|---|---|
| 1 | #1 강조어 (정말 / 너무 남발) | "정말 너무 정신없는 / 정말 많이 궁금 / 정말 너무너무 궁금하네요!!" → "정신없는 / 궁금했어요 / 궁금해요" (정말 1 회 살림) |
| 2 | #3 번역체 | "다름이 아니오라" → 삭제 |
| 3 | #11 hedging | "감사하겠습니다 🌷" → "알려주세요" (말줄임 자연) |
| 4 | #10 이모지 남발 | "😊 / 🙏 / ✨ / 🌷 / 💕" 5 개 → "😊" 1 개 |
| 5 | #5 판에 박힌 마무리 | "답장 기다리고 있을게요~ 💕" → "답장 기다릴게요!" |

### 보존 (친근 톤 strict)

- **첫 인사**: "안녕하세요! 정말 오랜만에 연락드려요" — 첫 "정말" 1 회는 친근 톤 시그너처라 살림
- **이모지 1 개**: 😊 — 친근 시그너처. 0 개로 깎지 않음 (DM 도메인의 personality)
- **호명**: OOO님 — 그대로
- **친근 어미**: ~해요 / ~인데 / ~인지 / ~할게요 — DM 도메인 디폴트
- **느낌표 1 개**: "답장 기다릴게요!" — 마지막 한 번은 따뜻함 보존

### 개선 포인트

- **"정말 / 너무" 거품 정리** — raw 에 6 회 등장 → 1 회. AI 가 친근함을 가장하면서 가장 흔히 남발하는 강조어.
- **이모지 5 개 → 1 개** — DM 에서 이모지가 3 개 이상 묶이면 AI 가 "친근 가장" 의 강한 시그널. 1 개만 의미 있는 자리에.
- **"다름이 아니오라" 삭제** — 카톡에서 이 격식 표현은 어색. 비즈니스 격식 메일에서 살리고 DM 에서는 뺀다.
- **마무리 단축** — "정말 감사하겠습니다 🌷" → "알려주세요" 로 자연스러운 부탁 톤.

### 한계

- **반말 vs ~해요체 판단 어려움** — DM 은 발신자·수신자 친밀도에 따라 반말 / ~해요체 / ~합니다체 가 달라짐. raw 에 ~합니다체 가 섞이면 톤 일관성 (#9) 문제. 이번 raw 는 ~해요체 일관 → 그대로 유지.
- **개인 personality 침해 위험** — 어떤 사람은 "정말 너무" 진심으로 자주 씀. **personal list 의 "유지어" 로 등록** 해서 보호하는 게 정답.

## 카톡·DM 도메인 적용 가이드

- **건드릴 것**: 강조어 (#1) 남발, 이모지 (#10) 3 개 이상 연쇄, 격식 번역체 (#3 일부)
- **건드리지 말 것**: 첫 인사 친근 표현 1 회, 이모지 0-1 개, 호명, 친근 어미 (~해요 / ~인데)
- **이모지 룰**: 3 개 이상 → 1 개로. 0 개로 깎지 마라 (DM personality 침해)
- **personal list 활용**: 친근 어휘 ("정말 / 진짜 / 너무 / 여러분") 가 본인 톤이면 "유지어" 등록
