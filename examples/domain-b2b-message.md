# B2B 메시지 도메인 — Raw vs Humanized

> 카톡 비즈니스 / 이메일 / 슬랙 외부 채널 등 ad-hoc 격식 B2B 메시지의 humanizer 적용. **풀 격식 (~합니다) 과 친근 어미 (~할게요) 혼합 OK**, hedging 일부 정리, "확인 가능하실까요?" 같은 과한 격식 단언으로 회복.

---

## 메타데이터

| 항목 | 값 |
|---|---|
| 도메인 | B2B 메시지 (카톡 비즈니스 / 슬랙 외부 / 비즈니스 DM) |
| 강한 카테고리 | #11 hedging, #3 번역체, #5 판에 박힌 마무리 |
| 톤 디폴트 | ~합니다체 + ~할게요 / ~드릴게요 혼합 (ad-hoc 격식) |
| 톤 보존 | 호명·격식 인사·"감사드립니다 / 부탁드립니다" 정형 |
| 금지 변경 | 회사명·담당자명·일정·금액·계약 조건 |

## 사례. 솔루션 도입 follow-up 메시지 (가상)

**프롬프트**
> 지난 미팅에서 소개한 솔루션 도입을 검토 중인 잠재 고객에게 카톡 비즈니스로 follow-up 메시지를 보내줘. 6-8 문장.

### Raw

> 안녕하세요 OOO 담당자님, Acme의 김OOO입니다. 지난 4월 23일 미팅에서 소개드린 한국어 NLP 솔루션 관련하여, 혹시 추가로 검토가 필요하신 부분이 있으실까요? 말씀드린 바와 같이 저희 솔루션은 기존 글로벌 솔루션 대비 응대 정확도가 평균 18% 향상될 수 있는 매우 우수한 성능을 보유하고 있습니다. 또한 도입 비용 또한 합리적인 수준으로 책정 가능하다는 점을 다시 한번 강조드리고 싶습니다. 가능하시다면 다음 주 중에 추가 미팅을 진행해 보시는 것은 어떠실까요? 일정상 어려우시다면 비대면 미팅으로도 충분히 진행 가능하다는 점, 참고해 주시면 감사하겠습니다. 항상 바쁘신 와중에 검토해 주셔서 진심으로 감사드리며, 회신 기다리고 있겠습니다.

`8문장 / 약 380자`

### Humanized

> 안녕하세요 OOO 담당자님, Acme의 김OOO입니다. 지난 4월 23일 미팅에서 소개드린 한국어 NLP 솔루션 관련해서, 추가로 검토가 필요하신 부분이 있을까요? 말씀드린 대로 저희 솔루션은 기존 글로벌 솔루션 대비 응대 정확도를 평균 18% 끌어올릴 수 있고, 우수한 성능을 보유하고 있습니다. 도입 비용도 합리적인 수준으로 책정할 수 있다는 점을 다시 한번 짚어드리고 싶습니다. 가능하시다면 다음 주 중에 추가 미팅을 진행해 보면 어떠실까요? 일정상 어려우시다면 비대면 미팅으로도 진행할 수 있습니다. 항상 바쁘신 와중에 검토해 주셔서 감사드리며, 회신 기다리고 있겠습니다.

`7문장 / 약 320자 (-16%)`

### 변경 (5 곳)

| # | 카테고리 | Before → After |
|---|---|---|
| 1 | #11 과한 hedging | "필요하신 부분이 있으실까요?" → "필요하신 부분이 있을까요?" (이중 존경 1 단계 완화) |
| 2 | #1 강조어 + #6 수동 | "평균 18% 향상될 수 있는 매우 우수한 성능" → "평균 18% 끌어올릴 수 있고, 우수한 성능" (능동 + 매우 삭제) |
| 3 | #7 또한 + #11 hedging | "또한 도입 비용 또한 ~ 책정 가능하다" → "도입 비용도 ~ 책정할 수 있다" |
| 4 | #11 hedging | "충분히 진행 가능하다는 점, 참고해 주시면 감사하겠습니다" → "진행할 수 있습니다" (단언 + 군더더기 삭제) |
| 5 | #5 판에 박힌 마무리 + 진심으로 | "진심으로 감사드리며" → "감사드리며" |

### 보존 (계약 정보 strict)

- **호명 / 회사명**: OOO 담당자님 / Acme / 김OOO
- **일정 / 수치**: 4월 23일 / 평균 18% / 다음 주 중
- **솔루션명**: "한국어 NLP 솔루션"
- **격식 인사**: "안녕하세요" / "감사드리며" / "회신 기다리고 있겠습니다" — 비즈니스 관계 시그너처
- **혼합 어미**: "~합니다 / ~할까요? / ~드리고 싶습니다 / ~할 수 있습니다" — ad-hoc 격식 표준

### 개선 포인트

- **이중 존경 (있으실까요?) 정리** — "있으실까요" 는 "있+으시+ㄹ까요" 이중 존경. 격식 강한 메시지에서 "있을까요" 로 1 단계 완화하면 자연.
- **"또한 ~ 또한"** — 한 문장 안에 "또한" 두 번 나오면 AI 의 강한 시그널. 첫 "또한" 삭제 + 두 번째 "또한" → "도".
- **"진심으로" 절제** — B2B 에서 "진심으로 감사드리며" 는 SDR 자동화 메시지의 시그너처. 1 회 "감사드리며" 만 살려도 진정성은 유지.
- **"활용" 의식적 회피** — 이번 사례에는 안 쓰임. B2B 에서 "활용" 은 #12 한국어 LLM 시그너처 의 강력 신호.

### 한계

- **격식 일관성 vs 친근함** — B2B 카톡에서 "~할게요" 같은 친근 어미를 너무 많이 쓰면 가벼움. raw 가 풀 격식이면 humanized 도 풀 격식 유지 (이번 사례). 친근 톤이 의도면 personal list 로 명시.
- **자동화 메시지 의심** — B2B follow-up 은 SDR 자동 발송 의심을 받기 쉬움. humanizer 가 다듬어도 발송 시점·주기가 너무 정확하면 AI 의심 그대로. **타이밍 / 개인 맥락 (지난 미팅 언급) 으로 차별화 필요**.

## B2B 메시지 도메인 적용 가이드

- **건드릴 것**: 과한 hedging (#11 있으실까요 / 가능하실까요), 거품 (#1 매우 / 진심으로 / 충분히), 번역체 (#3 ~ 바와 같이), 한국어 LLM 시그너처 (#12 활용 / 극대화)
- **건드리지 말 것**: 호명, 회사명, 일정·수치, 격식 인사 1 회, 혼합 어미 (ad-hoc 격식 디폴트)
- **이중 존경**: "~ 있으실까요? / 가능하실까요?" → "~ 있을까요? / 가능할까요?" 1 단계 완화
- **자동화 신호 회피**: 개인 맥락 1 줄 (지난 미팅·구체 일정·이름) 반드시 포함
