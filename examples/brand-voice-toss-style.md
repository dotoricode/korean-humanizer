# Brand Voice — Toss 풍 핀테크 (가상)

> 가상 핀테크 스타트업 "acme-fintech" 의 brand voice 프로필. 짧고 직설, 친근 격식 최소화. **실제 토스의 가이드를 사용한 게 아니라**, 한국 핀테크에서 자주 쓰는 톤을 추상화한 가상 케이스.
>
> 같은 spec 으로 자기 회사 brand voice 를 채울 때 참조용.

---

## Tone guide

- 1 문장 8-15 자 권장. 강조는 단어가 아니라 **문장 길이**로.
- 격식 인사 ("안녕하세요", "감사합니다") 는 **시작 / 마무리 1 회** 외 금지.
- 사용자를 "고객님" / "여러분" 으로 부르지 않는다. 그냥 "당신" / 생략 / "쓰는 분".
- 모든 동사는 평이형으로. ("제공해 드리고 있습니다" → "드려요" / "있어요")
- 숫자는 한국식. ("3.5 %" 보다 "3.5 퍼센트" 보다 "3.5 %" 그대로 — 표시는 raw 보존)
- 부정 표현 직설. ("쉽지 않습니다" → "어려워요")
- 비교는 "더" / "덜" 만. "보다 ~한" / "한층 더" / "더더욱" 모두 금지.
- 이모지 어떤 자리든 0 개. (이모지 없는 친근함이 토스 풍의 핵심.)
- 외래어 차용 (UX / API / SDK / 온보딩 등) 그대로 — 무리한 한글 대체 금지.

## Raw → Humanized 사례 3개

아래는 보존 규칙을 설명하기 위한 수동 편집 예시입니다. 특정 모델을 실행한 결과가 아닙니다. 짧은 문장 취향보다 사실·원문 어미·수정 한도·90% 길이 보존을 우선합니다.

### 사례 1 — 송금 서비스 소개

**Raw**:

> acme-fintech의 새 송금 서비스예요. 이 서비스를 통해 쉽고 빠르게 송금할 수 있어요. 궁금한 점은 고객 센터로 연락 주세요.

**Humanized**:

> acme-fintech의 새 송금 서비스예요. 이 서비스로 쉽고 빠르게 송금할 수 있어요. 궁금한 점은 고객 센터로 연락 주세요.

문자 수: 75 → 72자 (96.0%).

**적용 룰**:

- 3문장 중 가운데 1문장의 `이 서비스를 통해`를 `이 서비스로`로 치환
- 제품명·송금의 편의와 속도·고객 센터 안내·해요체 보존
- 원문에 없는 기능·확인 경로는 추가하지 않음

### 사례 2 — 앱 푸시 / 카피

**Raw**:

> 더욱 편리해진 송금 시스템을 통해 보다 빠르고 효율적인 금융 활동을 경험해 보세요!

**Humanized**:

> 더욱 편리해진 송금 시스템으로 보다 빠르고 효율적인 금융 활동을 경험해 보세요!

문자 수: 46 → 44자 (95.7%).

**적용 룰**:

- `송금 시스템을 통해`를 `송금 시스템으로`로 치환
- 편의·속도·효율성 주장과 권유 어미 보존
- 다른 후보는 수정 한도 안에서 다음 요청에 검토

### 사례 3 — 이메일 / 계좌 알림

**Raw**:

> 안녕하세요, 고객님. 항상 acme-fintech를 이용해 주셔서 감사합니다. 고객님의 계좌에 입금이 완료되었음을 알려드립니다. 자세한 내역은 다음과 같이 확인 가능합니다. 추가 문의 사항이 있으시면 언제든지 고객 센터로 연락 주시기 바랍니다.

**Humanized**:

> 안녕하세요, 고객님. 항상 acme-fintech를 이용해 주셔서 감사합니다. 고객님의 계좌에 입금이 완료되었다고 알려드립니다. 자세한 내역은 다음과 같이 확인 가능합니다. 추가 문의 사항이 있으시면 언제든지 고객 센터로 연락 주시기 바랍니다.

문자 수: 136 → 136자 (100.0%).

**적용 룰**:

- 5문장 중 입금 완료 안내 1문장의 명사형 표현만 치환
- 이메일의 감사·존칭·고객 센터 안내·합니다체 보존
- Brand voice의 해요체 취향으로 격식 이메일의 원문 어미를 바꾸지 않음
- 원문에 없는 앱·메뉴·확인 경로는 추가하지 않음

## 도메인 디폴트 ↔ 카탈로그 부록 E 매핑

이 Brand voice의 `domain_default: marketing`일 때 우선 검토할 카테고리입니다.

| 순위 | 카테고리 | 관련 설정 |
|---|---|---|
| 1 | #2 공허한 형용사 | `혁신적인` 등 ban |
| 2 | #12 고빈도 어휘 | `활용` / `극대화` / `솔루션` 등 ban |
| 3 | #1 강조어 | `보다 ~한` / `더더욱` 등 ban |

도메인이 이메일이면 격식·존칭·원문 어미를 먼저 보존합니다. `ending_default: ~해요`가 있어도 격식 이메일의 ~합니다체를 덮어쓰지 않습니다.

## 한계 / 주의

- 이 brand voice 는 문장을 짧게 만들지만, 일반 humanize 와 마찬가지로 정보량을 보존한다.
  - `length_bias: concise` 는 문장 길이와 어휘 밀도를 낮추라는 뜻이지, 주장 / 근거 / CTA 를 빼라는 뜻이 아니다.
  - 사용자가 "짧게"를 요청하지 않았다면 원문 대비 90% 미만으로 줄이지 않는다.
- "쉽게 / 빠르게 / 간편하게" 가 raw 에 있으면 **반드시 보존**. 이 단어가 곧 핀테크 톤이라서.
- 이모지 0 개 룰이 디자인 시스템 (앱 카피의 아이콘 / 일러스트레이션) 까지 막지는 않는다. **텍스트 안의 이모지** 만 금지.
