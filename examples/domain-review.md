# 제품 리뷰 도메인 — Raw vs Humanized

> 커머스 / 앱스토어 / 네이버 블로그 제품 리뷰의 humanizer 적용. **솔직 톤 strict 보존** — "혁신적인 / 다양한 / 효과적인" 같은 거품 형용사를 빼면 진정성이 살아남.

---

## 메타데이터

| 항목 | 값 |
|---|---|
| 도메인 | 제품 리뷰 (커머스 / 앱스토어 / 블로그) |
| 강한 카테고리 | #2 공허한 형용사, #1 강조어, #12 AI 고빈도 어휘 |
| 톤 디폴트 | ~다체 / ~해요체 (개인 톤에 따라) |
| 톤 보존 | 별점·구매일·제품명·솔직한 단점 표현 (의도된 부정 톤 살림) |
| 금지 변경 | 별점 / ★ 표기, 구매일, 제품명·SKU, 인용된 광고 문구 |

## 사례. 무선 키보드 한 달 사용 리뷰 (가상)

**프롬프트**
> 무선 키보드를 한 달 정도 사용한 리뷰를 별점 4/5 로 5-7 문장 써줘.

### Raw

> ★★★★☆ (4/5) — 2026년 3월 구매, 한 달 사용 후기.
>
> 이 키보드를 사용한 지 한 달 정도 되었는데, 결론부터 말씀드리면 정말 만족스럽게 사용하고 있습니다. 우선 키감이 매우 부드럽고, 타건음도 적절한 수준이라 사무실에서도 부담 없이 사용 가능합니다. 또한 무선 연결의 안정성도 매우 우수한 편이며, 배터리 수명도 광고된 사양과 거의 일치합니다. 다만 한 가지 아쉬운 점은, 키 배열이 다소 협소하여 적응 기간이 필요했다는 부분입니다. 그럼에도 불구하고 전체적인 완성도는 동급 제품 중 단연 뛰어난 수준이라고 평가하고 싶습니다. 다양한 환경에서 활용 가능한 멀티 디바이스 페어링 기능도 매우 유용했으며, 전반적으로 추천드릴 만한 제품이라고 사료됩니다.

`6문장 + 1 메타 / 약 360자`

### Humanized

> ★★★★☆ (4/5) — 2026년 3월 구매, 한 달 사용 후기.
>
> 이 키보드를 쓴 지 한 달 정도 됐는데, 결론부터 말하면 만족스럽게 쓰고 있습니다. 우선 키감이 부드럽고, 타건음도 적당한 편이라 사무실에서도 부담 없이 씁니다. 무선 연결 안정성도 우수하고, 배터리 수명도 광고된 사양과 거의 일치합니다. 다만 한 가지 아쉬운 점은, 키 배열이 다소 협소해서 적응 기간이 필요했다는 부분입니다. 그럼에도 전체적인 완성도는 동급 제품 중 단연 뛰어나다고 봅니다. 멀티 디바이스 페어링 기능도 유용했고, 전반적으로 추천드릴 만한 제품입니다.

`6문장 + 1 메타 / 약 280자 (-22%)`

### 변경 (5 곳)

| # | 카테고리 | Before → After |
|---|---|---|
| 1 | #1 강조어 + #12 활용 | "정말 만족스럽게 사용 / 매우 부드럽고 / 매우 우수한" → "만족스럽게 쓰고 / 부드럽고 / 우수하고" |
| 2 | #7 또한 + 거품 | "또한 무선 연결의 ~ 매우 우수한 편이며" → "무선 연결 안정성도 우수하고" |
| 3 | #3 번역체 | "그럼에도 불구하고 ~ 평가하고 싶습니다" → "그럼에도 ~ 뛰어나다고 봅니다" |
| 4 | #2 공허한 형용사 + #12 활용 | "다양한 환경에서 활용 가능한 ~ 매우 유용했으며" → "멀티 디바이스 페어링 기능도 유용했고" |
| 5 | #11 사료된다 + #5 판에 박힌 마무리 | "추천드릴 만한 제품이라고 사료됩니다" → "추천드릴 만한 제품입니다" |

### 보존 (제품 정보 strict)

- **별점**: ★★★★☆ (4/5) — 글자 단위 동일
- **구매일 / 사용기간**: 2026년 3월 / 한 달
- **제품 카테고리**: 무선 키보드 / 멀티 디바이스 페어링
- **솔직 단점**: "키 배열이 다소 협소해서 적응 기간이 필요했다" — humanizer 가 단점 톤을 *완화*하면 안 됨. 그대로 유지.
- **결론 단언**: "동급 제품 중 단연 뛰어나다고 봅니다" — 단언 톤 시그너처

### 개선 포인트

- **거품 정리 = 진정성 강화** — "정말 만족 / 매우 부드럽 / 매우 우수 / 매우 유용 / 다양한 환경 / 활용 가능" 거품 정리 후 → 솔직 후기 톤으로 인상 변화.
- **"~ 평가하고 싶습니다 / 사료됩니다"** — 리뷰 도메인에서 가장 흔한 격식 hedging. 단언으로 회복.
- **단점 보존** — humanizer 가 "다소 협소" 같은 정직한 부정 표현을 부드럽게 하지 않음 → 리뷰 신뢰도 유지.
- **22% 압축** — 강한 압축이지만 정보 손실 0. 거품만 정리.

### 한계

- **별점 표기 다양성** — ★ vs ⭐ vs 🌟 vs "(4/5)" 등 표기가 다양해서 humanizer 가 잘못 변환 가능. **personal list 에 "별점 표기 strict" 룰 추가** 권장.
- **광고 인용 vs 본인 의견 구분** — "광고된 사양과 거의 일치" 같은 인용은 그대로 둔다. 본인 평가 ("매우 우수") 만 정리.

## 제품 리뷰 도메인 적용 가이드

- **건드릴 것**: 거품 형용사 (#2), 강조어 (#1), 한국어 LLM 시그너처 (#12 활용 / 효과적인), 격식 hedging (#11 사료된다 / 평가하고 싶습니다)
- **건드리지 말 것**: 별점 표기, 구매일, 제품명·SKU·카테고리, 솔직한 단점 표현
- **단점 톤**: humanizer 가 부정 표현을 부드럽게 다듬으려 하면 안 됨 — 리뷰의 가치는 솔직함
