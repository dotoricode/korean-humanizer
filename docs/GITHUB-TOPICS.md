- `korean`, `korean-language`, `korean-nlp`: 한국어 전용 프로젝트라는 검색 신호

- `humanizer`, `prompt`, `writing-tools`, `style-transfer`: 사용 목적 검색 신호
- `claude-code`, `claude-skill`, `opencode`, `cursor`, `cursor-rules`, `chatgpt`: 실제 사용 환경 검색 신호
