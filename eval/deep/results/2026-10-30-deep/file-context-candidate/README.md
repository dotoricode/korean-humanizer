# Nimbus

Nimbus는 미리보기를 실행하는 도구예요. 이 예제는 의존성을 설치하지 않고 실행할 수 있어요.

## 처음 실행하기

1. Node.js와 npm을 사용할 수 있는 환경을 준비해요.
2. 터미널에서 `package.json`이 있는 프로젝트 루트로 이동해요.
3. 프로젝트 루트에서 다음 명령을 실행해요. `npm install`은 필요 없어요.

   ```sh
   npm run preview
   ```

실행하면 터미널에 다음 문구가 표시돼요.

```text
Nimbus preview
```

현재 예제는 이 문구를 출력하고 종료해요.

## 참고

- 설정 파일을 바꿨을 때만 프로젝트 루트에서 `npm run preview`를 다시 실행해요.
- 사용 안내는 [Nimbus 사용 문서](docs/usage.md)에서도 확인할 수 있어요.
