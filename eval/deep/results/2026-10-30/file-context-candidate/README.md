# Nimbus

Nimbus는 미리보기를 실행하는 예제 도구예요. 실행하면 터미널에 `Nimbus preview`가 출력돼요.

## 시작하기

Node.js와 npm을 사용할 수 있는 환경이 필요해요. 별도로 의존성을 설치할 필요는 없어요.

1. 터미널에서 이 README와 `package.json`이 있는 저장소 루트로 이동해요.
2. 저장소 루트에서 다음 명령을 실행해요.

   ```sh
   npm run preview
   ```

3. 터미널에 다음 문구가 출력되면 실행된 거예요.

   ```text
   Nimbus preview
   ```

## 다시 실행하기

설정 파일을 바꿨을 때만 저장소 루트에서 `npm run preview`를 다시 실행해요.
