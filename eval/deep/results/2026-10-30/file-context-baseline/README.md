# Nimbus

Nimbus는 미리보기 실행을 확인하는 예제 도구예요. 현재 예제를 실행하면 터미널에 `Nimbus preview`가 출력돼요.

## 실행 전 준비

Node.js와 npm을 실행할 수 있는 환경이 필요해요. 이 예제는 의존성을 설치할 필요가 없어요.

터미널에서 `package.json`이 있는 프로젝트 루트 폴더로 이동한 뒤, 아래 명령으로 Node.js와 npm을 사용할 수 있는지 확인해 주세요.

```sh
node --version
npm --version
```

버전이 출력되면 다음 단계로 진행해 주세요. 명령을 찾을 수 없다는 오류가 나오면 Node.js와 npm을 설치한 뒤 다시 확인해 주세요.

## 미리보기 실행

프로젝트 루트 폴더에서 아래 명령을 실행해 주세요.

```sh
npm run preview
```

터미널에 아래 문구가 출력되면 실행된 거예요.

```text
Nimbus preview
```

현재 예제는 이 문구를 출력한 뒤 종료돼요.

## 다시 실행하는 경우

설정 파일을 바꿨을 때만 미리보기를 다시 실행해 주세요. 실행 위치와 명령은 위의 미리보기 실행 단계와 같아요.

## 향후 지원 예정

오프라인 작업도 지원할 예정이에요.
