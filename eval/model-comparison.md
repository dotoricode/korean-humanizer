## 출력과 보존 확인

## 독립 자연스러움 검토

이전 보수적 출력과 최종 출력의 본문을 익명 A/B로 섞어 독립 검토자에게 비교하게 했습니다. 6쌍 모두 최종 출력을 선호했고, 보존 입력 4개를 포함해 실제 의미 변경·비문·보존 실패를 발견하지 못했습니다. 앞선 후보의 “더 정교하게”라는 개선 방향 추가는 최종 재실행에서 사라졌습니다.

이메일의 “변경해야 하는 상황이 되어 양해를 구하고자 합니다”는 장황하고, 다른 결과도 일정 변경 표현이 반복됩니다. 추가로 다듬을 여지가 있으며, 결과를 수동으로 고치지 않고 그대로 남겼습니다. 검토자 1명의 작은 비교이므로 제품 전체 품질의 성공률이나 향상률을 뜻하지 않습니다.

## 재현

위 소스 커밋의 SKILL.md와 references/ko-ai-signals.md를 JSON의 `request_template`에 그대로 넣고 각 입력마다 새 대화에서 실행합니다. 실행 옵션은 다음과 같습니다.

```bash
claude --print --model claude-opus-5-5 --effort medium --safe-mode \
  --no-session-persistence --strict-mcp-config \
  --mcp-config '{"mcpServers":{}}' --tools "" --output-format json < prompt.txt

codex exec --model gpt-6-astra -c 'model_reasoning_effort="medium"' \
  --ignore-user-config --ephemeral --sandbox read-only \
  --skip-git-repo-check --json --output-last-message output.txt - < prompt.txt
```
